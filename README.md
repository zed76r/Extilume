# Extilume

Extilume 是一个 macOS 菜单栏显示器工具，提供“外屏主屏”和“仅外屏（停用内屏）”两种模式，并在切回或退出时恢复本应用负责的显示配置。

首个 beta 版本为 **0.1.0-beta.1**，见[beta说明](docs/releases/0.1.0-beta.1.md)。仅外屏已完成本机基础功能及App主体验收，正式日用准入仍保留独立联合验收门槛；外屏主屏的既有验收见[本机矩阵](docs/menu-bar-primary-acceptance.md)。

仓库包含[双模式App说明](docs/internal-display-app.md)、[图标资产](assets/branding/)、[OpenSpec规格](openspec/specs/)和[默认只读的本机验证入口](docs/local-display-verification.md)。开发过程日志和逐次实验记录保留在本地，不纳入Git。

外接屏停用暂用“停用外接屏”描述动作，正式名称待定。**2026-10-30经用户确认，按当前这台直连HDMI显示器的手动停用／恢复范围完成交付，沿用现有显式启动方式，普通启动入口仍不新增。** 已有三轮Mac往返、正常退出重开、同屏同口确认恢复、PC手动使用及开盖后完整布局／责任结清证据，不再重复实机流程。菜单随状态在停用与恢复之间切换，停用使外屏退出Mac桌面，避免鼠标进入；输入能力未识别，软件切源保持不可用，由显示器自动选择有效信号或用户手动选源。动作前须开盖、内屏可操作，保持同一原屏和原Mac端口；睡眠、崩溃、换屏后的持续停用／自动恢复不作保证，真实VoiceOver未新增实测的限制如实保留。原保护锁与独立内屏模式状态不变。操作说明见[菜单候选说明](docs/menu-bar-primary.md#外屏交接候选)，交付边界与历史证据见[验证记录](docs/external-display-verification.md)。此结论不代表正式发布或其他配置可用。
