# Tasks

以下是实现与实机验收任务，完成情况以勾选及本轮验收记录为准。主屏路径的通过结论独立于内屏路径；内屏验证失败或未完成不能阻止已通过的主屏路径进入阶段一，也不能被算作阶段二通过。

## 1. 本机范围与只读验证入口

- [x] 1.1 建立最小 Swift 原生验证目标；以构建成功、启动默认只读且启动前后显示配置一致验证完成。
- [x] 1.2 读取系统、内外屏状态及物理连接链路，记录本轮验收环境；以脱敏报告明确开盖状态、目标外屏和连接方式验证完成。
- [x] 1.3 实现单物理外屏与非镜像范围判断；以镜像、多屏、虚拟或身份不明的输入自检确认均拒绝控制，并在可用本机拓扑上读回判定。
- [x] 1.4 说明只读启动、主动验证与停止方式；按说明运行一次，并确认报告不包含序列号、原始 UUID 或个人内容。

## 2. 恢复责任与配置来源

- [x] 2.1 实现一致布局组与内屏启用位的最小责任记录，控制前原子落盘；以完整性、用户权限及未完成事务不能清除责任的故障自检验证完成。
- [x] 2.2 实现最新 C、应用 B、未决配置来源的判定；用 A→B→C→B、C 后直接退出、自身回调、重连残留 B 的状态序列自检验证恢复目标正确。
- [x] 2.3 实现稳定身份重新匹配和缺失目标的适用部分恢复；以数字 ID 改变、目标缺失及身份冲突自检确认不会恢复到其他屏或静默清除未决责任。
- [x] 2.4 记录恢复数据边界与来源判定规则；核对说明与自检一致，并确认未控制的分辨率等设置不会从旧快照覆盖。

- [x] 3.4 验证公开事务作用域与显式补偿的相互作用，以及主进程异常退出后的最终布局；保留退出后及再次连接的读回证据，不能以提交成功替代结果。

- [x] 4.2 实现全过程进程事件等待与恢复归属协调；用主进程死亡、辅助进程死亡、旧代次和重启交错自检确认单一恢复执行者及未决责任保留。
- [x] 4.3 验证实际外屏连接链路的物理设备事件；记录实际拔线、设备事件和显示回调时间，确认不能把陈旧在线列表当作可用证明。
- [ ] 4.4 建立故障发生到实际恢复的单调计时与同步观测记录；以延迟通知输入自检确认检测延迟被计入，并记录物理拔线测量误差。
- [x] 4.5 编写辅助进程启动、恢复和清理说明；按说明运行一次不停用内屏的保护演练，确认保护在责任存在期间不提前退出。

## 5. 开盖内屏停用实测

- [x] 5.1 检查私有符号并实现受保护停用及启用；以符号缺失、外屏不明、记录失效和保护未就绪的故障自检确认内屏不会被停用。
- [ ] 5.2 在本机开盖状态实测真实停用；以活动桌面仅含物理外屏、鼠标及窗口不能进入内屏、键盘与触控板可用验证效果，记录正常恢复结果。
- [ ] 5.3 实测用户 C、重新应用、正常退出与睡眠唤醒；读回恢复目标及保护状态，确认恢复步骤不产生新的用户基准。
- [ ] 5.4 在停用准备、提交中、刚成功、稳定停用超过初始窗口、重新应用及恢复中测试主进程强退或崩溃；关键场景至少重复三次，逐次记录实际故障到内屏和适用配置恢复的时长，任何超时标记失败并停止新的停用。
- [ ] 5.5 实测物理拔线、辅助进程失效与睡眠唤醒边界故障；关键场景至少重复三次，记录自动恢复结果及完整计时，手动救援或自动图形会话重置不得算通过。
- [x] 5.6 测量稳定保护期间的内存、CPU 与唤醒频率；报告数值、单位和观测时长，并核对正常退出与异常恢复后无本轮遗留辅助进程。
- [x] 5.7 输出内屏路径的复现方法、已执行场景和失败或未验证范围；确认每条通过证据来自开盖实机，不借用旧系统项目结论。

2026-10-17：263 项 Swift、19 项 Python 测试、含 PTY hangup 的 6 种普通合同原生演练、11 组协议交错及内屏合同无写入启动／停止核验通过。已修复辅助进程 session 隔离，并为新内屏责任和握手增加启动会话与 IORegistry 对象绑定；原生 witness 验证不同 canonical UUID 的 proof 映射及无 proof 拒绝。首轮手动救援不追溯改判，旧失败记录已由恢复入口在原基准下独立核验为 `restored`，仍保留。

后续真实停用确认事务返回成功，独立读回核对内屏不活动、硬件 proof 一致且活动桌面仅为原物理外屏。曾因额外订阅 Embedded 服务的未分类私有 interest 就绪前撤权，各次失败及自动恢复证据保留。重新核对原规范后撤掉额外订阅：实际外屏候选仍持续观察并保守撤权；受控范围内已登记 Embedded 服务的匹配终止，必须现场读到明确 `Embedded` 且类别一致才单次排除，不使用不可读属性的缓存回退。角色／类别冲突、未知负向事件、重复终止和迟到匹配仍不能授权。

修正后 264 项 Swift 测试通过，其中覆盖符号缺失、外屏不明、责任失效、保护未就绪及提交前撤权拒绝原生调用。新版内屏合同无写入演练和真实停用→正常 `stop` 均通过；正常停止后的独立核验确认完整双屏基准、模式及内屏 proof 恢复，主、辅进程均退出，新记录为 `restored` 且保留，5.1 完成。

稳定真实停用期间资源重测 60.411 秒：RSS 起止 37.844／37.703 MiB，CPU 增量 14198 Mach tick，按本机 125/3 时基换算为 0.000591583 秒；package-idle 唤醒 0 次，interrupt 唤醒 5 次。CPU 换算已与 POSIX 进程 CPU 时钟交叉核验；这是端点采样，不代表峰值或长期负载。另在稳定停用超过 15 秒后对主进程、辅助进程强退各三次，故障动作至完整配置及内屏状态独立核验上界分别为 1.210840／1.129805／1.120793 秒和 1.226986／1.259162／1.227709 秒，每次均不超过十秒。三次正常停止及六次异常恢复后均无控制进程，十条测试记录全部 `restored` 且保留；最终原内屏主屏／外屏右上布局、模式与日常记录一致，UI 确认 ProMotion 和外屏可变 48–144 Hz 保留，5.6 完成。
