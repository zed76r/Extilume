## 2. 自动应用与恢复责任

- [x] 2.1 接入启动、显示回调、重连及睡眠唤醒的串行处理；以重复事件自检及本机连接、唤醒后只产生一轮稳定控制验证完成。
- [x] 2.2 接入支持范围与等待外屏状态；用不支持输入自检及本机无外屏、镜像场景确认不自动修改、不自动解除镜像。
- [x] 2.3 接入“保留当前配置”显式确认、C 持久化和自身事件排除；覆盖确认失败与并发变化自检，并实测手动修改不立即抢回、确认后下一次唤醒重新应用且基准为 C。
- [x] 2.4 接入持久责任、身份重匹配与未决恢复优先处理；用重连残留 B 和旧记录自检确认不能更新为原状、不能向其他屏恢复。
- [x] 2.5 记录自动应用触发条件、支持范围和最新用户配置恢复规则；按说明运行连接和用户 C 场景，核对说明与应用实际行为一致。

连接／唤醒合并、显式确认 C、不抢回手动配置、镜像拒绝及恢复责任均有对应自检和限定实机证据。确认只写恢复基准；退出后经独立读回才终验结清。

## 4. 退出与重新运行

- [x] 4.1 接入退出前冻结接管、恢复并读回的流程；在控制中退出及正常退出场景确认不发生新接管，独立观测在应用结束后核对最新 C。
- [x] 4.2 实现恢复失败时取消正常退出并保留责任；通过故障注入确认显示“恢复失败，尚未退出”、应用保持运行且重试恢复可用。
- [x] 4.3 验证强退后的公开事务回退与重新启动处理；读回最终布局并核对旧责任不会被删除或新运行覆盖，记录与正常退出不同的实际证据。
- [x] 4.4 记录退出、异常后重新运行与未决记录处理方式；按说明复现一次故障恢复，确认清理只发生在责任结清之后。

正常退出、C 直接退出与唤醒后退出、控制写入前取消、SIGKILL 后独立回退及旧责任优先处理均有证据。缺屏退出按保护规则取消，重连后重试正常退出，独立确认 C 后才结清；不强退绕过未决责任。
