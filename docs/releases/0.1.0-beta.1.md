# Extilume 0.1.0-beta.1

首个双模式beta，面向已有验证配置的试用。该版本准备本地安装包，尚未发布远程版本。

## 功能

- 外屏主屏：保留双屏桌面，将外接显示器设为主屏。
- 仅外屏：开盖时真正让内屏退出活动桌面，内置键盘和触控板继续使用；可直接从内屏主屏进入。
- 记住明确选择，勾号显示实际生效模式；启动后等待用户显式应用。
- 支持恢复双屏调整、确认新恢复布局、模式切回及退出恢复。
- 由同一构建内的独立辅助进程保护恢复责任，故障时保留门禁和未决记录。

## 验证及限制

App主体23/23完成：本机确认仅外屏效果、内置输入、跨模式、手动恢复布局和退出；44个菜单场景的实际呈现及交互通过。用户反馈当前设备的仅外屏已适合其日常使用，此反馈按本机试用体验记录。

正式准入仍以独立恢复提案及联合验收合格为前置，现有未验项和失败记录保留。此beta保留开发构建标识、显式启用及故障门禁，不自动解除已有保护故障，也不通过更换偏好域绕过历史责任。

安装包仅为本机构建的Apple Silicon（arm64）版本，最低系统声明为macOS 13；未宣称Intel、所有系统版本、显示器及连接方式均已验收。当前适用证据以已测试的单台物理外屏、非镜像配置为限，详见[验收记录](../internal-display-app-acceptance.md)。

## 试用

1. 先通过当前版本的“退出并恢复”正常结束会话，确认桌面恢复；同一桌面只运行一个版本。
2. 解压并启动`Extilume.app`，在菜单明确选择模式。此步骤需用户自行安排，不由构建或打包自动启动。
3. 已有故障或未决责任时保留拒绝状态；不要删除记录、清偏好或强制退出保护进程来绕过。
4. 结束试用时使用“退出并恢复”。历史版本和本地恢复记录保留，安装包不包含个人状态、偏好或现场日志。

本地beta使用ad hoc签名，尚无Developer ID签名或Apple公证；首次打开可能受到系统安全策略限制。

## 构建

```sh
python3 scripts/build-menu-bar-app.py --version 0.1.0-beta.1 \
  --output .local/releases/0.1.0-beta.1/Extilume.app -c release
```

该命令只构建隔离产物，不覆盖`dist/Extilume.app`或正在使用的App。对外发布前核对包内版本、源码提交、架构、签名和校验文件；提交、标签和远程发布分别记录，不能用本地产物代替发布结果。
