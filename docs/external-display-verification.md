# 外屏交接原型验证

本入口用于 `add-external-display-disable-mode` 的集中实机验收准备。模式与菜单候选已离线接入，普通启动仍由准入条件隐藏。离线测试、私有符号解析和构建成功不证明外屏可用，也不证明 PC 画面。默认启动 `extilume-probe` 仍只读；不自动发送 DDC 输入命令。

## 准备与边界

必须先获得当轮明确的显示写入授权。保持 Mac 开盖、内屏活动且可操作，只接一台当前范围支持的已确认物理 HDMI 外屏，关闭镜像。验证期间不要合盖、改布局、切换其他模式或同时启动其他显示控制器。输入源由用户使用显示器按钮切换。

使用独立的 `0700` 状态目录，绝不能指向现有应用或其他 change 的状态目录。目录由操作人事先创建，程序不会自动修复权限或删除旧责任。示例路径位于被忽略的 `.local/verification/`；详细设备身份、截图与过程只留在该目录，仓库只记录脱敏结论。

```sh
mkdir -p .local/verification/external-handoff
chmod 700 .local/verification/external-handoff
swift build -c release
```

以下用 `<probe>` 表示本轮构建的 `extilume-probe`，可由 `swift build -c release --show-bin-path` 定位。不要使用不同版本的二进制处理活跃责任。

## 只读核对

```sh
<probe>
<probe> --external-status .local/verification/external-handoff
```

`--external-status` 只读取记录与原目标状态，不获取写入权限；空目录报告没有责任。不能重认原目标时失败，不能以“外屏没有出现在活动列表”判定停用成功。查询不会创建恢复记录。

## 获得授权后执行的一轮

1. 记录当前完整双屏用户布局 C、Mac 可交互状态和显示器的 Mac/PC 输入端口；不要在输出中提交设备标识。
2. 显式执行停用（同时需要命令与写入开关）：

   ```sh
   <probe> --verify-external-disable --allow-display-write .local/verification/external-handoff
   ```

   程序先落盘 v4 责任，再用同一事务将主桌面调整到内屏并停用原外屏。独立辅助进程须重认原目标、确认非活动，同时确认唯一活动桌面为内屏。任何一步无法确认均失败，尽力补偿；补偿失败保留责任。系统睡眠或门禁失效会阻止新写入。
3. 人工验证内屏键盘、鼠标与窗口可交互，外屏桌面不再可进入。手动切显示器到 PC，确认实际 PC 画面和交互。命令返回不能代替这两项人工结论。
4. 停用命令保持进程、状态锁与电源观察，不退出，以维持 `.forAppOnly` 配置。在同一会话输入 `status` 只读核对；输入 `restore` 或 `stop` 恢复并核验后结束。恢复失败继续保留会话供重试。不要关闭终端来代替正常恢复；输入结束会尝试补偿，失败仍保留责任。

   原进程已结束时，保持线缆连接，用独立恢复入口：

   ```sh
   <probe> --recover-external --allow-display-write .local/verification/external-handoff
   ```

   原目标仍须完整重认，先启用外屏，再恢复适用 C。必要时先手动切回 Mac 输入使设备可读，再重试。成功后记录为 `restored` 并保留供终验；不会立即再次停用，也不改变显示器输入源。
5. 手动切回 Mac 输入，确认双屏桌面与 C，不使用拔线替代免拔线恢复。验证进程退出/重新启动后的目标读回要单列结果，不能把进程重启当作系统重启；异常结束后系统可能自行撤销 `.forAppOnly`，仍须独立核对，不能推断责任已恢复。

## 失败与恢复

先执行只读核对。停用失败不代表责任已恢复；只有 Mac 侧启用位和布局核验完成才可认为恢复结清。原目标缺失、身份改变、读回失联或来源不明时保留当前版本、状态目录和记录，接回原屏或手动切回 Mac 输入后重试上述外屏恢复命令。不要删除记录、使用主屏/内屏恢复命令、换成旧应用或向另一显示器发送写入。

同一次系统启动中数字 ID 改变可通过完整身份重新匹配；数字 ID 本身永远不是权限。系统重启后旧 boot/registry 绑定失效，目前拒绝写入，不自动重绑；此时保持开盖并记录失败，不能宣称跨系统重启恢复已通过。跨模式、睡眠和退出路径使用注入测试验证；长期生命周期仍待集中实机验收。
